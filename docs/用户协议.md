# 算一算 用户协议

生效日期：2026-09-24

## 一、服务说明
「算一算」是一款面向旧房/局部改造业主的装修算价工具，提供：
- 语音或手动录入房间尺寸；
- 自动生成房间平面图与家具布置示意图；
- 按主材/施工自动生成经济·舒适·轻奢三档预算及多空间总预算；
- 预算与图纸的本地保存与导出。

本服务当前为**免费试用阶段**，旨在帮助业主快速估算装修费用。

## 二、账号注册
您需提供称呼、手机号、所在城市以保存预算记录。您承诺所填信息真实有效。

## 三、平台积分（规划中）
未来版本可能推出「平台积分」：
- 积分用于兑换下载预算、生成示意图/效果图等额度；
- 积分通过每日登录、完善资料、分享等任务与活动获取，**非充值货币，不能直接购买**；
- 积分规则以届时小程序内公告为准。

## 四、预算免责声明
- 本工具输出的预算基于内置定额与您录入的尺寸/项目，**仅供参考**，不构成最终合同价格；
- 实际装修报价以与施工方/材料商的正式约定为准；
- 因录入错误、市场波动等导致的偏差，本平台不承担责任。

未来可能引入材料商品牌展示与轮播广告位，相关商品由材料商自行提供，平台不对商品质量与履约负责。

您不得利用本服务从事违法、侵权或干扰平台运行的行为。
