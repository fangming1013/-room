# 声控量房小程序（微信小程序 Demo）

语音报空间尺寸/门窗 → 自动施工图 → 选材 → 自动报价 → 效果图。绕开 Mac/iOS 编译，手机原生语音可用。

## 一、在您电脑上跑起来（Windows 即可，无需 Mac）

1. 下载**微信开发者工具**（Windows 稳定版）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开开发者工具 → 导入项目 → 目录选 `room-mini` 文件夹
3. AppID 选 **"测试号"**（本工程已填 `touristappid`，直接能编译）
4. 点"编译" → 点"真机预览" → 用您 iPhone 上的微信扫码，即可在手机上操作

## 二、手机上怎么用

1. **选空间**：厨房 / 卫生间 / 客厅 / 卧室 / 阳台 / 书房（各带专属选材和家具）
2. **录入尺寸**，三种方式任选：
   - 语音：按住"🎤 按住说话报尺寸"，说"厨房宽三米二深两米六高两米六，门在右窗在上"
   - 手绘：点"✏️ 手绘轮廓"，手指拖出矩形，自动按轮廓生成长宽
   - 手动：直接改宽/深/高、门/窗墙位和宽度
3. **摆家具**：语音说"放床放衣柜"，或点选
4. **主材素材**：勾选洁具/橱柜/瓷砖等，改数量 → 底部实时出预估合计
5. 点"生成施工图/效果图" → 三视图：施工图（墙/门窗/尺寸）/ 效果图（AI 示例）/ 报价单

## 三、关于语音（重要）

- **测试号模式**：微信不允许测试号用语音识别插件，所以语音按钮会弹出"预设示例"演示（点一下即自动填好，验证解析链路）。手绘+手动始终可用。
- **要真语音**：① 注册一个小程序账号（免费个人号，mp.weixin.qq.com）；② 后台"设置→第三方设置→插件管理"添加**微信同声传译**插件；③ 把 `project.config.json` 的 `appid` 改成您的真实 AppID。改完语音即点亮，手机说话直接转文字。

## 四、文件结构

```
room-mini/
  app.js / app.json / app.wxss        工程入口
  project.config.json                 测试号配置
  pages/index/                        录入页（空间/语音/手绘/选材/报价）
  pages/result/                       结果页（施工图/效果图/报价三视图）
  utils/spaces.js                     6 空间专属选材与主材定额价
  utils/parse.js                      中文语音/文本解析（尺寸/门窗/家具）
  utils/speech.js                     同声传译插件封装（带测试号降级）
  utils/quote.js                      报价计算
  assets/*.jpg                        4 张 AI 示例效果图
```
